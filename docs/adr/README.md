# Architecture decision records

One file per decision, numbered in the order the decisions were made. A record's decision is not rewritten after the fact. When a rule in it changes, it gets a dated amendment section; when a fact in it goes stale, the sentence is corrected; either way its status says it was amended. A decision replaced as a whole gets a new record that supersedes it, and the old one's status points at it.

Each record answers three questions. What was the situation, what did we decide, and what follows from that.
